===============================

This is fork of original repo by https://github.com/vadimonus/moodle-block_znanium_com

It's contains a code of plugin for Moodle Platform which enable seamless authentication
of Moodle Platform users in russian digital library system biblioclub.ru.

Плагин бесшовной аутентификации на сайте biblioclub.ru из Moodle
========================================

Это форк оригинального репо https://github.com/vadimonus/moodle-block_znanium_com

Данный репозитарий содержит исходный код плагина для платформы Moodle.
Плагин реализует возможность добавления блока в платформу Moodle. Блок содержит специальную ссылку для 
пользователей при переходе по которой, пользователь автоматически авторизуется платформой ЭБС Библиоклуб.

При настройке плагина треубется указать данные авторизации:
- домен
- секретный ключ

Эти данные вы можете получить обратившись в техническую поддержку biblioclub.ru.

Системные требования
--------------------
- Moodle 3.5.3 (сборка 2018051703) и выше: требуется Privacy API со списками пользователей.
- Проверено на Moodle 5.2.2 и PHP 8.4.

Установка
---------
Скачайте zip-архив со страницы релизов. Установите плагин через менеджер плагинов Moodle от администратора.

Совместимость с новой витриной ЭБС
----------------------------------

Начиная с v0.0.6, блок поддерживает новую витрину `biblioclub.ru`. Бесшовный
вход выполняется непосредственно на основном сайте ЭБС с использованием
fingerprint-сессии. После перехода пользователь авторизован в новой витрине;
переход через `old.biblioclub.ru` больше не используется.

Администратору Moodle не нужно менять домен организации или секретный ключ.
Они по-прежнему задаются в настройках блока.

Персональные данные / Privacy API
--------------------------------

Блок хранит историю переходов: идентификатор пользователя Moodle, контекст
перехода и время. Начиная с v0.0.7, эти записи доступны для экспорта и удаления
через стандартный Privacy API Moodle, включая удаление выбранных пользователей
в контексте. Запросы не затрагивают других пользователей или невыбранные контексты.

Для входа ЭБС получает идентификатор и логин пользователя, имя, фамилию,
необязательное отчество, домен организации и время авторизации. Логин Moodle
может быть адресом электронной почты. Передача описана в метаданных Privacy API.
Удаление истории в Moodle не удаляет учётную запись или данные на biblioclub.ru:
для этого нужно обратиться в ЭБС.
